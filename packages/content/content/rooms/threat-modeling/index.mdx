El bug más barato de arreglar es el que encuentras antes de escribir
código. El threat modeling es el hábito de mirar tu arquitectura y
preguntarse "¿cómo lo rompería alguien?" — sistemáticamente, con
frameworks (STRIDE) que convierten la intuición en checklist.

Este room aplica el método al diseño típico de una aplicación web y
conecta cada categoría de amenaza con las vulnerabilidades y rooms que
ya conoces: resulta que has estado explotando threat models ajenos todo
este tiempo.
