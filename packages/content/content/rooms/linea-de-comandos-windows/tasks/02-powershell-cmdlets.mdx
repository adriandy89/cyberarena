## Cmdlets: verbo-sustantivo

```powershell
Get-Process                # procesos
Get-Service                # servicios
Get-ChildItem              # listar (alias: ls, dir — ¡funcionan!)
Get-Content archivo.log    # cat
Get-Command *firewall*     # descubrir cmdlets
Get-Help Get-Process       # manual
```

La magia: la salida es un **objeto** con propiedades. Fíltrala y fórmatea sin grep:

```powershell
Get-Process | Where-Object CPU -gt 100 | Sort-Object CPU -Descending
Get-Service | Where-Object Status -eq 'Running' | Select-Object -First 10
Get-NetTCPConnection -State Listen
Get-LocalUser
```

Compara `Get-NetTCPConnection -State Listen` con el `netstat -ano` + findstr de cmd:
mismo resultado, sin parsear nada.

## Sistema y ejecución

```powershell
Get-ComputerInfo           # versión de Windows, RAM, dominio
whoami /priv               # mis privilegios (¿SeImpersonate? ¡potito!)
Get-ExecutionPolicy        # ¿puedo ejecutar scripts .ps1?
Set-ExecutionPolicy -Scope Process Bypass   # typical en labs
```

`whoami /priv` merece un marcador: el privilegio **SeImpersonatePrivilege** en un
servicio web es la puerta al clásico ataque Potato. Lo practicarás con lab en
Jr Pentester.
