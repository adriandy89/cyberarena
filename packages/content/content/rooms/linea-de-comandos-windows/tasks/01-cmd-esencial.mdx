## Los comandos que usarás siempre

```bat
dir                     :: listar (como ls)
cd Usuarios             :: cambiar directorio
type archivo.txt        :: como cat
copy a.txt b.txt        :: copiar
move b.txt ..\          :: mover
del b.txt               :: borrar
tasklist                :: procesos (como ps)
taskkill /PID 1234 /F   :: matar proceso
cls                     :: limpiar pantalla
```

## Diagnóstico de red desde cmd

```bat
ipconfig            :: mis IPs
ipconfig /all       :: + DNS, MAC, DHCP
ping 10.10.10.5     :: conectividad
tracert 10.10.10.5  :: saltos
netstat -ano        :: puertos + PID de cada conexión
arp -a              :: equipos conocidos en mi red local
route print         :: tabla de rutas
```

`netstat -ano` es tu `ss -tulpn` de Windows. El PID que muestra lo cruzas con
`tasklist | findstr <PID>` para saber qué programa escucha ahí.

## El comando net (ya lo conoces de AD)

```bat
net user                       :: usuarios locales
net user ana /add              :: crear usuario
net localgroup Administradores ana /add   :: meterlo en admins
net share                      :: recursos compartidos
```

En un lab de escalada, esa tercera línea suele ser el final feliz.
