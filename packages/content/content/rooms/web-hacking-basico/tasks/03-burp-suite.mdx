## El proxy que lo ve todo

Burp Suite (la Community basta para aprender) se pone EN MEDIO:

```text
Navegador ──► Burp (127.0.0.1:8080) ──► Servidor
```

Configura el proxy del navegador (o usa FoxyProxy) y desde ese momento:

- **Proxy > Intercept**: congela cada petición. Edítala (cambia el precio, el
  parámetro, la cookie) y Forward. Ya no necesitas "copy as fetch": control total.
- **HTTP History**: todo lo que ha pasado, listo para repetir (Repeater).
- **Repeater**: envía UNA petición N veces con retoques — el taller del web hacker.

## El resto del arsenal (lo usarás en el path Jr Pentester)

- **Intruder**: automatiza listas (usuarios, IDs, payloads) contra un parámetro.
- **Decoder**: base64/hex/URL al instante.
- **Comparer**: diff entre dos respuestas (¿en qué se diferencia el admin del user?).

Con DevTools MIRAS; con Burp TOCAS. En Jr Penetration Tester lo dominarás (módulo
Burp Suite) y en Web Application Pentesting atacarás con él laboratorios vulnerables
(SQLi, XSS…) — esta base te basta para empezar a jugar en los labs de CyberArena hoy
mismo.
