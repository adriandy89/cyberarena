## Práctica: content discovery contra el lab

```bash
# Fuzzing con gobuster:
gobuster dir -u http://127.0.0.1:18089 -w /usr/share/wordlists/dirb/common.txt

# O manualmente (robots.txt ya te da pistas):
curl http://127.0.0.1:18089/robots.txt
# Disallow: /admin
# Disallow: /backup
# Disallow: /dev
```

```bash
# Sigue el redirect del /dev:
curl -L http://127.0.0.1:18089/dev
```

robots.txt, directory listing y redirects son las tres técnicas que acabas de practicar
contra un servidor real. En un pentest, este discovery toma 30 segundos y puede
revelar paneles de admin, backups y entornos de desarrollo.
