## Cinco ramas que gobernarán tu enumeración

```text
HKEY_CLASSES_ROOT   (HKCR)  asociaciones de archivos
HKEY_CURRENT_USER   (HKCU)  configuración del usuario actual
HKEY_LOCAL_MACHINE  (HKLM)  configuración de TODA la máquina  ← la mina
HKEY_USERS          (HKU)   todos los perfiles cargados
HKEY_CURRENT_CONFIG         perfil de hardware actual
```

Abre el editor con **regedit** (o desde terminal: `reg query ...`). Rutas que
memorizarás para siempre:

```powershell
# Autoarranque (persistencia clásica):
HKCU\Software\Microsoft\Windows\CurrentVersion\Run
HKLM\Software\Microsoft\Windows\CurrentVersion\Run

# Versión exacta del sistema (enumeración):
HKLM\SOFTWARE\Microsoft\Windows NT\CurrentVersion
```

Cada programa instalado deja rastro en `HKLM\SOFTWARE`. Cada "ombi" (programa
portátil que se ejecuta sin instalación) también lo deja en `HKCU\SOFTWARE`. El
Registry es la forma más rápida de responder: ¿QUÉ hay instalado, QUÉ arranca solo y
QUÉ versión de Windows es exactamente?
