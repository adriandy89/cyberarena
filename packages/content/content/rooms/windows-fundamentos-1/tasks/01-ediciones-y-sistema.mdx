## Un ecosistema, muchas ediciones

**Home** (consumo), **Pro** (dominio + BitLocker + Escritorio remoto), **Enterprise**
(GPO completas, corporativo) y **Server** (los controladores de dominio que atacarás
en Active Directory). La edición define qué técnicas de ataque/aprovechamiento existen.

## El sistema de archivos: NTFS y sus carpetas clave

| Ruta | Qué hay |
|---|---|
| `C:\Windows` | el sistema (System32 = binarios críticos) |
| `C:\Program Files` | software de 64 bits |
| `C:\Program Files (x86)` | software de 32 bits |
| `C:\Users\<usuario>` | perfiles (Documentos, Escritorio, NTUSER.DAT…) |
| `C:\ProgramData` | datos de aplicaciones (oculto, escribible por usuarios) |

NTFS trae **ACLs granulares** (más ricas que rwx), **flujos alternativos (ADS)** para
esconder datos (`archivo.txt:oculto`) y **journaling**. En AD verás también unidades
de red mapeadas y recursos compartidos (`\\servidor\recurso`).

Herramientas de gestión que ya debes reconocer: **Panel de Control**, **Administración
de equipos** (usuarios locales, servicios, visor de eventos) y **msconfig/taskmgr**
para procesos y arranque.
