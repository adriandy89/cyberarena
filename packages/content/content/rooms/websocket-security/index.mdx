Los WebSockets abren un canal persistente que atraviesa proxies y
firewalls "porque es web". Pero la manida frase "los WebSockets no
tienen CSRF" escondió durante años dos bugs que este room practica
contra un chat real (servidor RFC 6455 implementado desde cero):

1. **Message injection**: el server confía campos del mensaje que
   deberían venir de la sesión.
2. **Sockets internos sin auth ni Origin**: ese endpoint "solo para el
   panel de admin" al que cualquiera puede conectar.
