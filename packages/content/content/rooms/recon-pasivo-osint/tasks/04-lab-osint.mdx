## Práctica: OSINT contra TechCorp

El lab simula la web corporativa de "TechCorp Solutions". Todo lo que necesas está
accesible PÚBLICAMENTE — no exploit, solo saber mirar:

### 1. robots.txt
```bash
curl http://127.0.0.1:18091/robots.txt
```

### 2. Código fuente (HTML comments)
```bash
curl -s http://127.0.0.1:18091/about | grep -i flag
curl -s http://127.0.0.1:18091/ | grep -i admin
```

### 3. Archivos de configuración
```bash
curl http://127.0.0.1:18091/.env
```

### 4. Seguir pistas
Los HTML comments del home revelan que hay un admin panel. Sigue la pista.

**Esto es exactamente lo que un atacante hace en los primeros 5 minutos contra
cualquier web corporativa — sin enviar un solo paquete de ataque.**
