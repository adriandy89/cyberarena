## ¿Qué puertos tengo abiertos y quién los usa?

```bash
ip a                    # mis interfaces e IPs (sucesor de ifconfig)
ss -tulpn               # puertos TCP/UDP escuchando + proceso
ping -c 3 8.8.8.8       # ¿hay salida a internet?
traceroute 8.8.8.8      # camino de saltos
```

`ss -tulpn` es de las primeras cosas que ejecutarás en una máquina comprometida:
**servicio escuchando solo en 127.0.0.1** = posible movimiento lateral clásico
(binded localhost, accesible vía SSH tunnel). Escuchando en `0.0.0.0` = todas las
interfaces, potencialmente expuesto.

## curl: tu navaja suiza HTTP

```bash
curl http://127.0.0.1:8080/           # GET simple
curl -I http://ejemplo.com/           # solo cabeceras
curl -X POST -H 'Content-Type: application/json' \
     -d '{"user":"ana"}' http://api.local/login
curl -o archivo.zip URL               # descargar
```

Ya conoces curl del lab de recon — aquí lo confirmas como herramienta diaria. En el
módulo de Networking profundizaremos en TCP/IP, DNS y capturas con Wireshark.
