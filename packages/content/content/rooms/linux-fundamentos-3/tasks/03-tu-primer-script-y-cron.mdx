## Scripts: guardar comandos para el futuro

```bash
#!/usr/bin/env bash
# enumerar.sh — primera ronda de reconocimiento de una máquina
set -e
echo "== identidad =="; whoami; id
echo "== suid ==";    find / -perm -4000 -type f 2>/dev/null
echo "== puertos =="; ss -tulpn | head -15
```

Guárdalo como `enumerar.sh`, dale permisos y ejecútalo:

```bash
chmod +x enumerar.sh
./enumerar.sh            # o bash enumerar.sh
```

Variables (`DESTINO=10.10.10.5`, luego `$DESTINO`), bucles (`for puerto in 22 80 443`) y
condicionales convierten comandos en herramientas propias. En el módulo de scripting
del path Jr Pentester harás un escáner de puertos en bash y Python.

## Cron: el tiempo también ejecuta código

```bash
crontab -e               # editar TUS tareas
cat /etc/crontab         # tareas del sistema
ls -la /etc/cron.d/      # tareas por paquete
```

Formato: `minuto hora día-del-mes mes día-de-la-semana comando`.

```
30 3 * * * /usr/local/bin/backup.sh
```

Para un atacante, un cron de root que ejecuta un script escribible es escalada
inmediata; para un defensor, revisar cron es parte de la caza de persistencia.
