## CIA: el objetivo de todo

**Confidencialidad** (solo quien debe, ve), **Integridad** (los datos no se alteran
sin autorización), **Disponibilidad** (el sistema está cuando se necesita). Todo
control de seguridad protege alguna de las tres. Añade autenticación y no-repudio
para el quinto elemento (AAA).

## El mapa de roles (los que ya sabes reconocer)

| Rol | Hace | Palabras clave |
|---|---|---|
| **Pentester** | ataques autorizados + informe | el "red team" comercial |
| **Red teamer** | simula adversarios reales, sigilo | TTPs, evasión |
| **Analista SOC** | monitoriza y responde | SIEM, triaje (tu módulo 10) |
| **DFIR** | forense + respuesta a incidentes | evidencia, timeline |
| **Threat hunter** | busca lo que las alertas no vieron | hipótesis, anomaly |
| **AppSec / DevSecOps** | seguridad en el código y el pipeline | SDLC, SAST/DAST |
| **GRC** | normas, riesgo, auditoría | ISO 27001, NIST |

Ninguno es "mejor": son perspectivas del mismo problema. La tuya empieza por el que
más te haya enganchado de este path.
