Linux domina los servidores, la nube y las herramientas de seguridad ofensiva. En este
room aprenderás a sobrevivir (y disfrutar) en la línea de comandos: identificar tu
usuario, orientarte en el sistema de archivos y manipular archivos con soltura.

Puedes practicar en WSL, una VM Linux o incluso Git Bash (los comandos básicos coinciden).
