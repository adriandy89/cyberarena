## El ciclo de vida de un archivo

```bash
mkdir -p proyectos/ctf/notas    # crea toda la rama de directorios
touch informe.txt               # crea vacío (o actualiza su fecha si existe)
cp informe.txt copia.txt        # copiar
mv copia.txt ~/Documentos/      # mover (¡y renombrar: mv a.txt b.txt!)
cat informe.txt                 # ver contenido entero
head -n 5 informe.txt           # primeras 5 líneas
tail -f /var/log/syslog         # seguir un log en vivo (Ctrl+C para salir)
rm copia.txt                    # borrar archivo
rm -rf proyectos                # borrar directorio y todo su contenido — SIN PAPELERA
```

`rm -rf` no perdona: no hay Ctrl+Z. Léelo dos veces antes de Enter, sobre todo si
empieza por `/` o lleva `*`.

## Buscar cosas

```bash
find /etc -name "*.conf"            # archivos por nombre
find / -type f -size +100M 2>/dev/null   # archivos enormes (errores a /dev/null)
grep -i "error" app.log             # texto dentro de archivos (-i ignora mayúsculas)
grep -r "password" ./configuración  # búsqueda recursiva
```
