## Práctica en el laboratorio

Levanta el lab (panel arriba) y entra con:
```bash
docker exec -it lab-linux-explore-shell-1 su - explorer
```

### Ejercicio 1: dotfile oculto
```bash
ls -la ~                          # -a muestra archivos ocultos (que empiezan por .)
cat ~/.secret_flag                # ¡ahí está la flag!
```

### Ejercicio 2: buscar en archivos del sistema
```bash
grep FLAG /etc/passwd             # busca la palabra FLAG en passwd
```

Estos son EXACTAMENTE los comandos que usarás en cada máquina comprometida.
