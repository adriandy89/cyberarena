## Nadie se sabe todos los comandos

```bash
man ls          # manual completo (q para salir)
ls --help       # resumen de opciones
man -k password # buscar en los manuales por palabra (apropos)
```

## Tuberías y redirección: la filosofía UNIX

Cada comando hace UNA cosa bien; los compones con `|` (pipe):

```bash
cat acceso.log | grep "401" | wc -l        # ¿cuántos accesos no autorizados?
ps aux | grep nginx                        # procesos de nginx
history | grep ssh                         # ¿qué ssh he ejecutado?
```

Redirección de salida:

```bash
echo "hola" > saludo.txt     # crea/sobrescribe
echo "otra línea" >> saludo.txt   # añade (append)
comando 2> errores.txt       # solo stderr a archivo
comando > /dev/null 2>&1     # silencio total (todo a la nada)
```

## Comandos estrella para más tarde

```bash
sort | uniq -c | sort -nr    # top de repetidos (verás esto MUCHO en CTFs)
cut -d: -f1 /etc/passwd      # primera columna de un archivo delimitado por :
awk '{print $1}'             # primera columna de texto tabulado
```
