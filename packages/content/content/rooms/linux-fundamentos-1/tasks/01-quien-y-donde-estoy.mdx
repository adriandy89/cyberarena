## Identidad y ubicación

Dos preguntas existenciales de la terminal, con dos comandos de respuesta:

```bash
whoami     # tu usuario
pwd        # tu directorio actual (print working directory)
```

El **prompt** también te da pistas: `usuario@host:~$` significa que estás en tu home
(`~` es el atajo de `/home/tu-usuario`). La `$` indica usuario normal; si vieras `#`,
eres root (¡cuidado con lo que escribes!).

## Navegación básica

```bash
ls          # listar contenido
ls -l       # detalle: permisos, tamaño, fecha
ls -la      # detalle + ocultos (los que empiezan por .)
cd /etc     # ir a un directorio absoluto
cd Documentos   # relativo (desde donde estés)
cd ..       # subir un nivel
cd ~        # volver a home
cd -        # volver al directorio anterior
```

Truco: la tecla **Tab** autocompleta nombres — úsala sin piedad. Y `Ctrl+L` limpia la
pantalla (más rápido que escribir `clear`).

## Jerarquía estándar (FHS)

En Linux todo cuelga de `/` (root del sistema, no confundir con el usuario root):

| Ruta | Contenido |
|---|---|
| `/home` | carpetas personales de usuarios |
| `/etc` | configuración del sistema |
| `/var/log` | logs |
| `/tmp` | temporales |
| `/usr/bin` | ejecutables instalados |

A diferencia de Windows, no hay `C:\`: las rutas usan `/` y no hay letras de unidad.
