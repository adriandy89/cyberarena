## Levanta el laboratorio

Usa el comando del panel **Laboratorio** de esta página (arriba). Cuando el contenedor
esté listo, compruébalo:

```bash
curl http://127.0.0.1:18080/
```

Deberías ver la página de bienvenida. Nada sensible… a simple vista.

## robots.txt: el mapa que los sitios regalan

`robots.txt` es un archivo público que indica a los buscadores qué NO indexar. La ironía
es obvia: **acabas de recibir la lista de sitios interesantes**.

```bash
curl http://127.0.0.1:18080/robots.txt
```

La línea `Disallow:` contiene una ruta. Visítala:

```bash
curl http://127.0.0.1:18080/secreto/
```

Ahí espera tu primera flag real de laboratorio. Guárdala para la pregunta final de
esta tarea.

> En un pentest real, robots.txt, sitemap.xml y archivos de backup (`.old`, `.bak`,
> `.git/`) son las primeras paradas del reconocimiento pasivo.
