## La respuesta dice más que el cuerpo

Las cabeceras HTTP de respuesta informan sobre el servidor (Server, X-Powered-By) y
a veces contienen **secretos olvidados**. Pídele solo las cabeceras al servidor:

```bash
curl -I http://127.0.0.1:18080/
```

Entre las habituales hay una cabecera personalizada `X-…` que no debería estar ahí.
La flag que contiene es la respuesta final de este room.
