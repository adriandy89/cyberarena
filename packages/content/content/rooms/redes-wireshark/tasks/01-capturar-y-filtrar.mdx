## Tu primera captura

1. Abre Wireshark → selecciona tu interfaz activa (eth0/wlan0)
2. Haz clic en Start (icono azul)
3. Navega a alguna web → verás paquetes en tiempo real
4. Stop (icono rojo)

## Display Filters (tu herramienta diaria)

```text
http                          → solo HTTP
tcp.port == 443               → solo HTTPS
ip.addr == 10.10.10.5         → tráfico hacia/desde esa IP
ip.src == 10.10.10.5          → solo desde esa IP
dns                           → solo consultas DNS
tcp.flags.syn == 1            → solo SYNs (inicio de conexiones)
http.request.method == "POST" → solo POSTs
!(http or dns)                → todo EXCEPTO HTTP y DNS
```

## La estructura de 3 paneles

```text
┌──────────────────────────────────────────┐
│ 1. Packet List: cada paquete en una línea │
│    (nº, tiempo, source, dest, protocol)   │
├──────────────────────────────────────────┤
│ 2. Packet Details: capas del protocolo    │
│    (Ethernet → IP → TCP → HTTP → Data)    │
│    Clic en ▶ para expandir cada capa      │
├──────────────────────────────────────────┤
│ 3. Packet Bytes: el hex dump crudo        │
│    (lo que literalmente viaja)            │
└──────────────────────────────────────────┘
```

**Clic derecho en un paquete → Follow → TCP Stream**: reconstruye la conversación
completa en texto plano. Es la forma más rápida de ver credenciales HTTP, comandos
FTP o sesiones Telnet.
