## Directory listing: la información gratis

El lab tiene un **FileShare** con directorio listing habilitado:

```bash
curl http://127.0.0.1:18087/files
```

Verás archivos públicos Y archivos que no deberían estar ahí:
- `flag_level1.txt` — accesible directamente
- `.env` — archivo de configuración con credenciales

## El .env: la fuga más común de todas

El patrón es idéntico en apps reales: el `.env` con claves de API, contraseñas de
BD y secrets se sube al servidor y queda accesible porque nadie bloqueó el acceso
a archivos ocultos.

```bash
curl http://127.0.0.1:18087/files/.env
# DB_PASSWORD=FLAG{dotenv_credentials_leak}
```

En producción real, ese archivo tendría credenciales de AWS, tokens de Slack,
claves de base de datos... todo lo que la app necesita para funcionar.

## Directory listing también es información

`/files` sin autenticación ya es un hallazgo del informe: "información expuesta
por directory listing". Pero lo interesante viene en el siguiente task: subir
archivos que NO deberían poder subirse.
