## Configuración de 30 segundos

1. Burp Proxy > Options: escucha en `127.0.0.1:8080` (default).
2. Navegador: proxy HTTP a `127.0.0.1:8080` (o FoxyProxy para activar/desactivar).
3. Visita `http://burp` en el navegador → certificado CA de Burp → instálalo como
   confianza de CA (para HTTPS).

## El flujo de trabajo diario

```text
Navegador → Burp Proxy → HTTP History → (analizar) → Repeater → (modificar/repetir)
```

- **Intercept ON**: congela cada petición para editarla EN VIVO.
- **Intercept OFF** (recomendado por defecto): todo pasa libre, pero se GUARDA en
  **HTTP History** — revísala después con filtros.

## Target: el mapa del sitio

La pestaña **Target > Site map** construye un árbol con TODAS las URLs descubiertas
(por navegación o por fuzzing desde Burp). Es tu inventario del objetivo:
- Rutas descubiertas automáticamente
- Parámetros de cada endpoint
- Response headers de cada URL

Clic derecho en cualquier petición del History → **"Send to Repeater"** (Ctrl+R) o
**"Send to Intruder"** (Ctrl+I) para el siguiente nivel.
