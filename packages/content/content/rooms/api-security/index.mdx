Las APIs tienen su propio top 10 de OWASP, y los dos primeros puestos no
son inyecciones ni overflow: son **fallos de autorización**. BOLA (acceder
a objetos de otros) y BFLA (ejecutar funciones de otros) dominan los
incidentes reales de APIs porque las apps autentican correctamente...
y luego olvidan autorizar cada recurso.

Este room ataca CorpAPI, la API de una tienda donde eres `alice` (usuario
normal, id=2). Cuatro vulnerabilidades esperan.
