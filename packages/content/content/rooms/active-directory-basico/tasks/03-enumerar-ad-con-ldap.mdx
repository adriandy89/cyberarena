## LDAP: el idioma de AD

Active Directory habla **LDAP** (Lightweight Directory Access Protocol, puerto 389/636).
Enumerar AD = hacer preguntas LDAP al DC: "dame todos los usuarios", "¿quiénes son
Domain Admins?", "¿qué equipos hay?".

```powershell
# Desde un Windows del dominio, sin herramientas extra:
net user /domain              # usuarios del dominio
net group "Domain Admins" /domain
```

El binario histórico: **net** (¡sí, net!). Con más potencia usarás PowerShell
(`Get-ADUser -Filter *`) o herramientas ofensivas (enum4linux, BloodHound — este
último mapea rutas de ataque completas y lo verás en Jr Pentester).

## DNS: la guía telefónica del dominio

AD está casado con su DNS interno: el dominio `corp.local` vive ahí. Los registros
**SRV** (`_ldap._tcp.corp.local`) anuncian qué máquinas son DCs y qué servicios
ofrecen (Kerberos, LDAP…). Por eso "el DNS está roto" en una red corporativa suele
significar "AD está roto".

Con esto cierras el módulo Windows/AD: ediciones y Registry, UAC y el modelo de
dominio. Siguiente parada: redes — cómo viajan realmente tus paquetes.
