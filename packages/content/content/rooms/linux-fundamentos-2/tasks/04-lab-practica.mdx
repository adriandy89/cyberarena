## Práctica en el laboratorio

### Ejercicio 1: buscar en logs
```bash
grep -r "secret" /var/log/        # recursivo: busca en todos los archivos
```

### Ejercicio 2: permisos de grupo
```bash
id                                 # verifica que estás en el grupo flagreaders
find / -name "*flag*" 2>/dev/null # encuentra los archivos con flag
ls -la /opt/group_only_flag.txt    # mira los permisos: r--r-----
cat /opt/group_only_flag.txt       # puedes leerlo porque eres del grupo
```

La lección: los permisos Unix no son solo rwx para dueño — el grupo Y otros importan.
