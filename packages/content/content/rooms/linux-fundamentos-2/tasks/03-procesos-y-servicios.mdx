## Todo lo que corre es un proceso

```bash
ps aux                     # todos los procesos, con usuario
ps aux | grep sshd         # ¿está corriendo el ssh?
top / htop                 # procesos en vivo (CPU, memoria)
kill <PID>                 # SIGTERM: "por favor, termina"
kill -9 <PID>              # SIGKILL: muerte inmediata, sin limpieza
```

Cada proceso tiene un dueño. Ver un proceso corriendo como **root** que no debería
(tu app, un script) es oro para un atacante — y una alerta para un defensor.

## Servicios con systemd

```bash
systemctl status nginx     # estado de un servicio
systemctl list-units --type=service --state=running
journalctl -u nginx -f     # logs del servicio en vivo
```

Los servicios (demonios, nombres acabados en `d`: `sshd`, `systemd-resolved`) suelen
arrancar con el sistema y correr como root o con cuentas dedicadas (`www-data`).

## Enumeración express de una máquina

Cuando comprometas un Linux, esta será tu primera ronda:

```bash
whoami && id               # quién soy
sudo -l                    # qué puedo escalar
find / -perm -4000 -type f 2>/dev/null   # SUID
ps aux | head -20          # qué corre y COMO quién
cat /etc/crontab           # tareas programadas
```

Guarda estos comandos: repetirás esta lista en cada lab del path. Has terminado la
base de Linux — en los siguientes módulos la usarás para atacar de verdad.
