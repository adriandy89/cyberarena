## Anatomía de un ls -l

```text
-rwxr-x--- 1 ana dev 2048 nov 1 12:00 script.sh
│└┬┘└┬┘└┬┘     └─ grupo
│ │  │  └── otros (resto del mundo)
│ │  └───── grupo (dev)
│ └──────── dueño (ana)
└────────── tipo: - archivo, d directorio, l enlace
```

Cada trío suma con **r=4, w=2, x=1**:

- `rwx` = 7 · `r-x` = 5 · `r--` = 4 · `---` = 0
- Por eso `chmod 754 script.sh` deja el archivo exactamente `rwxr-xr--`.

En **directorios**, `x` no es "ejecutar" sino **poder entrar** (cd). Un directorio con
`r` sin `x` lista nombres pero no deja acceder.

## Cambiar permisos y dueños

```bash
chmod u+x script.sh        # simbólico: u/g/o/a + - r/w/x
chmod 754 script.sh        # octal: dueño-grupo-otros
chown ana:dev script.sh    # cambiar dueño y grupo (necesita privilegios)
```

`sudo` ejecuta como root: `sudo chown root:root fichero`. Úsalo con respeto, y consulta
`sudo -l` (¿qué puedo hacer como root?) — un clásico de enumeración en CTFs.
