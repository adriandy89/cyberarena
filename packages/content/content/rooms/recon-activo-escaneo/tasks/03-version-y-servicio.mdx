## El flag que cambia todo: -sV

```bash
nmap -sV -sS -p 22,80,443,445 10.10.10.5
```

Sin `-sV`, Nmap dice "puerto 80 open". Con `-sV`:

```text
PORT   STATE SERVICE VERSION
22/tcp open  ssh     OpenSSH 8.2p1 Ubuntu 4ubuntu0.3
80/tcp open  http    Apache httpd 2.4.49 ((Unix))
443/tcp open  ssl/https Apache httpd 2.4.49
445/tcp open  netbios-ssn Samba smbd 4.6.2
```

**Ese output es la entrada del exploit**: versión exacta → searchsploit → CVE.

## OS detection y scripts NSE

```bash
nmap -O 10.10.10.5              # adivina el SO por el stack TCP/IP
nmap -sV --script=banner 10.10.10.5    # captura banners de los servicios
nmap --script vuln 10.10.10.5    # scripts de vulnerabilidades conocidas (¡ruidoso!)
```

Los **scripts NSE** (Nmap Scripting Engine) son la artillería: desde detectar
EternalBlue (`smb-vuln-ms17-010`) hasta enumerar usuarios de SMB
(`smb-enum-users.nse`). Hay +600 oficiales: `ls /usr/share/nmap/scripts/`.

## El flujo profesional completo (memorízalo)

```bash
# 1. Quién está vivo
nmap -sn 10.10.10.0/24
# 2. Qué puertos (rápido primero)
nmap -sS --top-ports 100 -oA scan_rapido <vivos>
# 3. Todos los puertos en los interesantes
nmap -sS -p- -oA scan_completo <objetivo>
# 4. Versiones + scripts en los puertos abiertos
nmap -sV -sC -p <abiertos> -oA scan_versiones <objetivo>
# 5. searchsploit <versión> → exploit
```

`-oA` guarda en tres formatos (normal, grepable, XML) para procesar después. `-sC`
ejecuta los scripts "default" (seguros y útiles).

Con este flujo puedes enumerar cualquier red en minutos. El siguiente módulo (Nmap
Pro) lo lleva al nivel profesional, y después Burp Suite hace lo mismo para
aplicaciones web.
