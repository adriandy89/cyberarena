## El primer barrido

Antes de escanear puertos necesitas saber QUIÉN está vivo en el rango:

```bash
# Nmap ping sweep (ICMP + ARP en local)
nmap -sn 10.10.10.0/24           # -sn = sin port scan, solo discovery
nmap -sn -PR 10.10.10.0/24       # ARP only (redes locales: lo más fiable)

# Alternativas clásicas
fping -asg 10.10.10.0/24         # rápido y silencioso
arp-scan --localnet              # puro ARP: descubre lo que bloquea ICMP
```

## Por qué ARP > ICMP en redes locales

Un firewall bien configurado bloquea ping ICMP (entrante). Pero **ARP** es necesario
para que la red funcione: si la máquina no responde ARP, no puede comunicarse. Por eso
`arp-scan` en la misma subred encuentra TODO lo encendido, incluso hosts "ocultos".

En redes remotas (no local): ARP no llega — se usan ICMP, TCP SYN a puertos comunes
(80, 443) y UDP. Nmap combina técnicas con `-sn` por defecto.

## El resultado esperado

Una lista de IPs vivas. Cada una es un objetivo para el port scan del siguiente task.
En un pentest de red interna, este barrido puede descubrir máquinas olvidadas (la
impresora con FTP abierto, la Raspberry del laboratorio, el Windows Server 2003 que
nadie parchea).

> **Ruido**: un ping sweep a /24 es MUY visible en cualquier SIEM. En engagements con
> reglas de sigilo se acuerda ventana y técnica con el cliente.
