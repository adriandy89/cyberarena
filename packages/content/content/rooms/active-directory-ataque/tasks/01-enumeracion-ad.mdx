## BloodHound: el mapa del tesoro

```bash
# 1. Recolección (en la máquina comprometida)
SharpHound.exe -c All                # recopila TODO el dominio a un .zip
# o desde Linux con impacket:
bloodhound-python -u user -p pass -d corp.local -dc dc01.corp.local -c All

# 2. Análisis (en tu máquina con la GUI de BloodHound)
# Importa el .zip → el grafo se pinta → "Find Shortest Path to Domain Admins"
```

BloodHound responde la pregunta mágica: **"¿Cómo llego de MI usuario actual a Domain
Admin?"** Las rutas típicas que descubre:

- Tu usuario → miembro de `Help Desk` → puede resetear la contraseña de un admin
- Tu usuario → tiene sesión en un servidor → ese servidor tiene un servicio con
  credenciales de Domain Admin
- Tu usuario → puede escribir en una GPO → la GPO aplica al DC

## PowerView / Enumeración manual

```powershell
# Módulo de PowerShell clásico (anterior a BloodHound)
Get-DomainUser                          # todos los usuarios
Get-DomainGroup "Domain Admins" -Members
Get-NetComputer                         # todos los equipos
Find-LocalAdminAccess                   # ¿dónde soy admin local?
Get-DomainGPO                           # políticas de grupo
```

## El flujo profesional

1. Shell en cualquier máquina del dominio (phishing, exploit, share abierto).
2. **Enumerar** con BloodHound → grafo de rutas.
3. Seguir la ruta más corta (a menudo 2-3 saltos).
4. En cada salto: la técnica del siguiente task (Kerberoast, Pass-the-Hash, etc.).

> Sin BloodHound, enumerar AD a mano es como buscar un libro en una biblioteca sin
> catálogo: posible, pero brutalmente lento.
