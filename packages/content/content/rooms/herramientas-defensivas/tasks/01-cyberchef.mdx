## El "cilindro de operaciones" de GCHQ

**CyberChef** (gchq.github.io/CyberChef, corre offline en tu navegador) encadena
operaciones: la salida de cada una alimenta la siguiente.

```text
Input: RkxBR3s=  →  [From Base64]  →  [ROT13]  →  FLAG{...}
```

Operaciones estrella para el día a día:
- **From/To Base64, Hex, URL** — los decodificadores de siempre.
- **ROT13, XOR** — retos y malware simple.
- **Extract IPs / URLs / emails** — de un log o un binario sucio.
- **Magic** — ¡adivina la cadena de operaciones por ti! (prueba: pega el ROT13+base64
  de tus rooms anteriores y pulsa Magic).

Para un analista: examinar cabeceras, decodificar payloads de phishing, extraer IOCs
de un log. Para un CTF: el 50% de los retos de "decoding".

No necesita instalar nada: descarga el HTML y funciona offline (ideal para evidencias
sin exponerlas a internet).
