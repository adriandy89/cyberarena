## Distribuciones preparadas

- **REMnux**: Ubuntu cargado de herramientas para análisis de malware y evidencias:
  decodificadores, analizadores de PDF/Office, network sniffing, scripts de extracción
  de IOCs.
- **FlareVM**: lo mismo pero sobre Windows (PS> instalador que convierte una VM en
  laboratorio de reverse engineering: debuggers, dissectores de PE, DE compilers).

## La regla de oro del laboratorio

```text
VM de análisis  ←→  red solo-host / host-only  (NUNCA bridge a tu LAN)
```

Malware se detona en la VM con la red aislada (o con INetSim/FakeNet simulando
internet para ver a qué "llama"). Snapshots ANTES de detonar: analizar → restaurar →
repetir. Un analista sin snapshots acaba reinstalando todo muy a menudo.

## Cerrando el círculo del path

Ya conoces ambos lados: atacar (recon, exploits, tooling ofensivo) y defender (SOC,
logs, SIEM, análisis). El último módulo del path conecta esto con TU carrera.
