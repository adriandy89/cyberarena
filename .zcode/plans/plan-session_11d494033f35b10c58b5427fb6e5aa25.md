## 2. Certificados PDF descargables (server-side, pdfkit)

- **Dep**: `pdfkit` + `@types/pdfkit` en `apps/api` (JS puro, sin deps nativas — funciona en la imagen slim).
- **`@repo/shared`**: exportar `CertificateItem` (hoy duplicado en web page y dashboard).
- **API** `apps/api/src/gamification/certificate-pdf.service.ts`: A4 horizontal con el diseño de la tarjeta web (marca CyberArena, nombre, path, fecha, XP) + **código de verificación** `sha256(userId|pathSlug|completedAt)[:16]`. Etiquetas ES/EN por `?locale=`.
- **Endpoint**: `GET /api/me/certificates/:slug/pdf` (SessionGuard) → `application/pdf` con `Content-Disposition: attachment`. 404 si el path no está completo.
- **Web**: botón "Descargar PDF" en `apps/web/app/[locale]/certificate/[slug]/page.tsx` (fetch blob same-origin vía rewrite + objectURL); se conserva el botón imprimir. Añadir clave de mensaje ES/EN.
- **Tests**: spec de unidad del builder (Buffer empieza con `%PDF`, contiene nombre/título); verificación manual end-to-end contra el dev stack (usuario de prueba + `QuestionSolved` insertadas del path más corto vía script node + curl del PDF).
