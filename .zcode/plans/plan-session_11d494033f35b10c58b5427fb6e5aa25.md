## Tecnología de labs (patrones ya probados)

- **Pattern A (Web)**: `python:3.12-alpine` + `http.server` + stdlib — cero builds, cero pip
- **Pattern B (Multi-puerto)**: `python:3.12-alpine` + `socket` TCP — banners reales
- **Pattern C (Linux shell)**: `alpine` + entrypoint que configura SUID/sudo/cron
- **Pattern D (OSINT)**: nginx + páginas estáticas + secrets en metadata/robots
- **Pattern E (Challenge)**: python app que sirve retos progresivos

Todos con: red interna aislada, 127.0.0.1 only, cap_drop ALL, flags por env.
