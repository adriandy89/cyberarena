# Spec 103 — Content Pack: Advanced Pentesting (Red Teaming / PT2)

- **Estado:** en implementación
- **Creada:** 2026-11-01

## 1. Propósito

El quinto y último path: nivel experto (PT2). Las técnicas que separan un pentester
junior de un operador de red team: evasión, AD avanzado, containers, cloud y AI/LLM.

## 2. Módulos

| # | Módulo | Rooms | Estado |
|---|---|---|---|
| 1 | web-red-team | 1 (evasión WAF, payloads polimórficos, C2 web) | 🚧 |
| 2 | ad-avanzado | 1 (delegación Kerberos, ADCS, NTLM relay, trusts) | 🚧 |
| 3 | containers-cloud | 1 (container escape, IAM misconfig) | 🚧 |
| 4 | ai-llm-exploitation | 1 (prompt injection, data exfiltration via LLM) | 🚧 |

## 3. Criterios de éxito

- [ ] Cada room con contenido experto original, comandos reales y flags autocontenidas.
- [ ] Build verde, seed, catálogo con 4 paths.
